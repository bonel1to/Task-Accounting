# УП.03. Этап 1. Входной аудит проекта

Проект: «Учёт задач небольшой команды».

Данный комплект подготовлен для входного аудита проекта, разработанного на УП.02 и используемого как основа для УП.03.

## Краткое описание

Приложение предназначено для локального учёта задач небольшой команды. Пользователь может создавать задачи, назначать исполнителя, задавать срок, статус и приоритет, просматривать список задач, канбан-доску, комментарии и статистику.

## Стек

- HTML
- CSS
- JavaScript
- localStorage для локального хранения данных

Проект является статическим frontend-приложением. Backend, база данных, пакетный менеджер и внешние зависимости не используются.

## Запуск

1. Открыть папку проекта.
2. Открыть файл `index.html` в браузере.
3. Проверить отображение интерфейса и работу основных сценариев.

Установка зависимостей и запуск сервера не требуются.
