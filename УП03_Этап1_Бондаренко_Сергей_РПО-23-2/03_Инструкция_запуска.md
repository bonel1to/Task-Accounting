# Инструкция запуска проекта

## Название проекта

Учёт задач небольшой команды

## Требования

- Любой современный браузер: Chrome, Edge, Firefox или аналогичный.
- Node.js не требуется для запуска приложения, но может использоваться для проверки синтаксиса JavaScript командой `node --check script.js`.
- Установка зависимостей не требуется.

## Запуск на другом компьютере

1. Скачать или клонировать репозиторий:

   ```bash
   git clone https://github.com/bonel1to/Task-Accounting.git
   ```

2. Открыть папку проекта:

   ```bash
   cd Task-Accounting
   ```

3. Проверить наличие основных файлов:

   ```text
   index.html
   styles.css
   script.js
   README.md
   ```

4. Открыть файл `index.html` в браузере.

5. Проверить работу приложения:

   - отображается форма создания задачи;
   - отображается список задач;
   - работает карточка задачи;
   - работает канбан-доска;
   - работает переключение светлой и тёмной темы;
   - данные сохраняются в `localStorage` браузера.

## Проверка JavaScript

Дополнительно можно выполнить:

```bash
node --check script.js
```

Ожидаемый результат: команда завершается без ошибок.

## Конфигурация

Файл `.env` для запуска не требуется. Секретов, токенов и паролей в проекте нет. Для отчётности подготовлен пример `.env.example`.

## Возможные проблемы

Если данные в интерфейсе выглядят некорректно, можно нажать кнопку «Сбросить данные». Приложение восстановит демонстрационный набор задач.
