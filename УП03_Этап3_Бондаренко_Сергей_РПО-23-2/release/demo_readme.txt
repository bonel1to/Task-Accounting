Task-Accounting portable demo

Project: Учёт задач команды
Type: static HTML/CSS/JavaScript frontend

How to run:
1. Extract project_release.zip.
2. Open index.html in a browser.
3. Check the main scenario:
   - create a task;
   - select assignee, deadline, priority and status;
   - edit the task card;
   - add a comment;
   - verify the task appears in the list and kanban board.

Primary deployment for stage 3:
https://bonel1to.github.io/Task-Accounting/

This archive is a fallback portable demo for checking the result without an IDE.
