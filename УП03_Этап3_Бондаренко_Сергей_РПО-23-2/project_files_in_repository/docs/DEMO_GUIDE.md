# DEMO_GUIDE.md

## Как быстро проверить проект

1. Открыть публичную ссылку:

```text
https://bonel1to.github.io/Task-Accounting/
```

2. Дождаться загрузки интерфейса "Учёт задач команды".
3. Проверить основной сценарий:
   - создать новую задачу;
   - выбрать исполнителя, срок, приоритет и статус;
   - убедиться, что задача появилась в списке и на канбан-доске;
   - открыть карточку задачи и изменить статус;
   - добавить комментарий;
   - переключить светлую/темную тему;
   - нажать "Сбросить данные", если нужно вернуть демонстрационное состояние.

## Что считается успешной проверкой

- приложение открывается по публичной ссылке;
- основные блоки интерфейса отображаются без ошибок;
- задача создается и редактируется;
- фильтрация и канбан обновляются;
- комментарий сохраняется;
- критических ошибок в deploy log нет.
