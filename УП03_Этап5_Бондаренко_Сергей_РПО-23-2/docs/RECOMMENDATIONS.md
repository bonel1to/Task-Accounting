# RECOMMENDATIONS.md

## Рекомендации по безопасности

1. Поддерживать `.gitignore` в актуальном состоянии и не коммитить реальные `.env`, ключи, токены, дампы БД и backup-файлы.
2. Оставлять в репозитории только безопасные примеры окружения: `.env.example`, `.env.demo.example`, `.env.production.example`.
3. Перед каждым этапом сдачи запускать `scripts\security-check.bat`.
4. При появлении зависимостей добавить обязательный `npm audit`, `pip-audit` или аналогичный инструмент в CI.
5. При появлении backend API добавить проверку ролей, владельца ресурса, CORS, allowed hosts и подробности ошибок production-режима.
6. При появлении базы данных настроить регулярный backup и отдельную restore-проверку на тестовом окружении.
7. Хранить пользовательские данные на сервере, если проект будет использоваться не как учебный статический прототип.
8. Добавить мониторинг доступности GitHub Pages или будущего сервиса.
9. Периодически проверять GitHub Actions и DevTools Console на повторяющиеся критические ошибки.
