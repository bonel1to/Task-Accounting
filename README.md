# Учёт задач команды

Простой учебный прототип системы учёта задач для небольшой команды. Приложение реализовано как статический фронтенд без сборки и без внешних зависимостей.

## Возможности

- создание задач;
- редактирование и удаление задач;
- просмотр списка задач;
- канбан по статусам;
- фильтрация по статусу и исполнителю;
- режим просмотра `Все задачи` / `Мои задачи`;
- приоритеты, сроки и отметка просроченных задач;
- комментарии к задачам;
- светлая и тёмная темы;
- сохранение данных в `localStorage`.

## Стек

- HTML
- CSS
- JavaScript
- `localStorage` для локального сохранения состояния

## Структура проекта

```text
.
```

## Запуск

1. Склонировать репозиторий.
2. Открыть `index.html` в браузере.

Сборка, установка пакетов и запуск сервера не требуются.

## Данные

- Демонстрационные данные описаны в `script.js`.
- Текущее состояние задач сохраняется в `localStorage`.
- Выбранная тема интерфейса тоже сохраняется в `localStorage`.

## Назначение проекта

Проект подходит как учебный пример интерфейса для трекинга задач: здесь есть единое клиентское состояние, фильтрация, редактирование сущностей и локальное хранение данных без бэкенда.
